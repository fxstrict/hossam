# Hossam License Manager Pro

مركز إدارة عملاء وتراخيص نظام الحسام للمحاماة — بديل احترافي كامل لأداة CMD
`tools/license-generator/generate-license.js`، بحسب المواصفة في
`برنامج ادارة الاشتراكات وتوليد الليسنز.txt`.

تطبيق PWA مستقل (لا يحتاج سيرفر، لا يحتاج Node على جهاز الاستخدام اليومي)
يعمل بالكامل في المتصفح: كل البيانات تُخزَّن محليًا في IndexedDB، وكل عمليات
توقيع التراخيص تتم بمفتاح ECDSA عبر Web Crypto API — بنفس الخوارزمية
وصيغة التوقيع المستخدمة في `js/license/LicenseCrypto.js` داخل تطبيق الحسام
نفسه، بحيث تعمل أي رخصة تُصدر من هنا فورًا مع أي نسخة مثبَّتة من الحسام دون
أي تعديل على التطبيق الأساسي.

## التشغيل

هذا تطبيق ثابت (Static PWA) — لا يوجد باك-إند. لتشغيله:

```bash
# من داخل مجلد المشروع
python3 -m http.server 8080
# أو: npx serve .
```

ثم افتح `http://localhost:8080` في المتصفح. **يجب** تشغيله عبر خادم محلي
(HTTP) وليس بفتح `index.html` مباشرة بصيغة `file://`، لأن IndexedDB و
Service Worker (خاصية PWA للعمل بدون إنترنت) لا يعملان على بروتوكول
`file://` في أغلب المتصفحات.

عند أول فتح: التطبيق يطلب إنشاء حساب **Super Admin** واحد (اسم + اسم
مستخدم + كلمة مرور 8 أحرف على الأقل)، ثم يدخل مباشرة.

### تفعيل التوقيع

من صفحة **الإعدادات → مفتاح التوقيع**، لديك خياران:

- **إذا سبق وولّدت مفتاحًا عبر أداة `generate-license.js`:** الصق محتوى ملف
  `tools/license-generator/keys/private-key.pem` في تبويب "استخدام المفتاح الحالي".
- **إذا لم تولّد أي مفتاح بعد (الحالة الشائعة لغالبية المستخدمين):** لا حاجة
  لسطر الأوامر أو Node.js إطلاقًا. اضغط تبويب **"توليد مفتاح جديد"**، ثم زر
  "توليد زوج مفاتيح جديد الآن" — سينشئ لك التطبيق مباشرة من المتصفح:
  1. زر تنزيل `private-key.pem` (احتفظ به في مكان آمن — نسخة احتياطية وحيدة).
  2. زر تنزيل `license-public-key.js` **جاهزًا تمامًا للاستخدام** — فقط استبدل
     به الملف الموجود على المسار `js/license/license-public-key.js` داخل
     مشروع الحسام مباشرة، دون أي نسخ أو تعديل يدوي لمحتواه.

**لن يُخزَّن المفتاح الخاص على أي قرص أبدًا** — يبقى في ذاكرة المتصفح لهذه
الجلسة فقط، ويجب إعادة لصقه أو توليده بعد كل إغلاق للمتصفح أو تحديث للصفحة.
هذا قرار أمني مقصود، وليس نقصًا — راجع `docs/SECURITY.md`.

```

manifest.json, service-worker.js, offline.html    ملفات PWA

                             Router، KeySession، Modal، Toast، EventBus
js/crypto/LicenseCrypto.js  توقيع/تحقق ECDSA متوافق 100% مع تطبيق الحسام
js/repositories/            7 مستودعات: عملاء، أجهزة، اشتراكات، تراخيص،
                             فواتير، مستخدمون، إعدادات
js/modules/                 كل الشاشات: Dashboard، العملاء، معالج إصدار
                             الترخيص السباعي، التراخيص، الفواتير، التقارير،
                             سجل العمليات، المستخدمون والصلاحيات RBAC،
                             النسخ الاحتياطي، الإعدادات
js/vendor/qrcode.js         مكتبة QR كود (MIT، بدون CDN) — انظر
                             js/vendor/QRCODE_LICENSE.txt
assets/icons/                أيقونات PWA بكل المقاسات المطلوبة
tests/                      49 اختبار Node (توافق تشفير، منطق أعمال،
                             اختبار شامل يشغّل الواجهة الحقيقية عبر jsdom)

```

## الاختبارات

```bash
npm install   # يثبّت fake-indexeddb و jsdom و qrcode-generator (لأغراض
               # الاختبار فقط — التطبيق نفسه لا يحتاج أي منها في المتصفح)
node tests/test-crypto-compat.js   # توافق التوقيع مع تطبيق الحسام الحقيقي
node tests/test-repositories.js    # منطق كل المستودعات
node tests/test-engines.js         # Dashboard/بحث/تقارير
node tests/test-issuer.js          # تدفق إصدار الترخيص الكامل
node tests/smoke-app.js            # اختبار شامل يشغّل index.html الحقيقي
                                    # في متصفح محاكى (jsdom) ويكرر رحلة
                                    # مستخدم كاملة: تسجيل → عميل → المعالج
                                    # السباعي → تجديد → نقل جهاز → بحث
```

كل الـ 50 اختبارًا تنجح حاليًا (0 فشل) — راجع
`docs/PHASE_31_LICENSE_MANAGER_PRO_REPORT.md` للتفاصيل الكاملة.

## ما لم يُنفَّذ عمدًا (مؤجَّل ضمن "المميزات المستقبلية" بنص المواصفة الأصلية)

- تذكيرات تلقائية عبر واتساب/بريد (تحتاج سيرفر/API خارجي؛ التطبيق الحالي
  يوفّر روابط `wa.me` و`mailto:` جاهزة بدلًا من الإرسال الآلي).
- بوابة دفع إلكتروني مباشرة.
- كوبونات خصم، وإدارة وكلاء/موزّعين.
- إلغاء الترخيص عن بُعد فوريًا: لا يوجد سيرفر مركزي في هذا المشروع أو في
  تطبيق الحسام نفسه حاليًا؛ الإلغاء يعمل تمامًا كما هو موثّق في
  "كتالوج استخدام نظام الترخيص" §7 (تعديل يدوي في جدول جوجل شيتس)، وهذا
  التطبيق يولّد الصف الجاهز للصقه تلقائيًا بدل كتابته يدويًا.

هذه كلها مذكورة صراحة في ملف المواصفة الأصلي تحت "المميزات المستقبلية"،
وليست نقصًا في التنفيذ.
